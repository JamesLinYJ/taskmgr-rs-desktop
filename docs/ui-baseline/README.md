本目录是新仓库内可长期保留的 UI 事实来源。被忽略的 `achieved/taskmgr-rs-win32-reference/` 只用于人工追溯结构与行为；正式实现、视觉验收与测试不得依赖其中的文件。

## 坐标与缩放

- 原始窗口模板 `264 × 247 DLU` 与 `MS Shell Dlg 8pt` 仅用于恢复页面比例、锚点和信息密度。
- Flutter 使用逻辑像素与集中式令牌；不把 DLU 当物理像素，也不逐像素复制旧 Win32 控件皮肤。
- 100% 缩放以 `flutter_app/test/goldens/desktop_*.png` 为视觉验收基线；125%、150%、200% 验证布局与文本不溢出。
- 系统标题栏、窗口边框和平台字体光栅化不纳入 golden。
- 菜单层级、页序、列序、按钮顺序、快捷键和数据语义保持稳定；圆角、色彩、阴影与分隔遵循当前 `DesktopTheme`。

## 行为验收

- 表格支持列拖动宽度、按表头排序、单选、高亮、方向键、Enter、双击和右键菜单。
- PID 动作携带 PID 与创建时间；执行前 Rust 再验证身份。
- 500ms 高速刷新不阻塞 Flutter UI isolate，不改变当前选择或滚动位置。
- 快照失败保留上一份数据并显示 stale/error；只读不到一个字段时只影响该单元格。
- 八种语言、四档缩放下不得出现 RenderFlex overflow。
- X11、GNOME Wayland、KDE Wayland 缺少窗口协议时，操作必须随能力禁用；不得使用假窗口数据。
